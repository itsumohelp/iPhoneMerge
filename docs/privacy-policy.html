プライバシーポリシー

本アプリ「iPhoneMerge」（以下、「本アプリ」）をご利用いただきありがとうございます。本アプリは、ユーザーのプライバシーを尊重します。

収集する情報

本アプリは、個人情報を一切収集しません。氏名、メールアドレス、位置情報などのデータは収集・保存・送信しません。

クリップボードへのアクセス

テキスト貼り付けボタンをタップした場合のみ、クリップボードの内容を読み取ります。取得した内容は端末内でのみ使用し、外部サーバーへの送信は行いません。

ネットワーク通信

URLを指定してファイルを取得する機能において、ユーザーが明示的に入力したURLにのみアクセスします。それ以外のネットワーク通信は行いません。また、通信内容を収集・保存することはありません。

ローカルストレージ

比較履歴は端末内（UserDefaults）にのみ保存されます。クラウドや外部サービスへの送信は行いません。

サードパーティSDK・広告

本アプリはサードパーティのSDK・広告・解析ツールを一切使用していません。

Privacy Policy

Thank you for using "iPhoneMerge". This app respects your privacy.

Information We Collect

This app does not collect any personal information. No names, email addresses, location data, or any other personal data are collected, stored, or transmitted.

Clipboard Access

Clipboard content is read only when the user explicitly taps the paste button. The content is used solely on-device and is never sent to any external server.

Network Access

The app accesses only URLs explicitly entered by the user for file comparison. No other network communication takes place, and no communication data is collected or stored.

Local Storage

Comparison history is stored only on-device (UserDefaults). Nothing is sent to the cloud or any external service.

Third-Party SDKs & Advertising

This app does not use any third-party SDKs, advertising networks, or analytics tools.
